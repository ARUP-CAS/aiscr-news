---
title: New AMCR API
excerpt: A new AMCR API has been released.
badge: Update
---

Since June 2019, a new API interface has been made available as part of the AIS-2 project, which is used for bulk data extraction from AMČR via the OAI-PMH protocol. The API, including all documentation, is available at <https://api.aiscr.cz/>. You can now directly connect AMČR as a data source in your projects!
